# 定长音频生成归因与编谱能力实验计划

2026-10-23。用户要求保留的计划。当前执行优先级由用户更新为：**先继续训练此前训练不足的模型，允许过拟合，观察既有结构在现有训练数据上的能力；以下新架构/课程实验暂不启动。** 续训不能宣称证明了理论能力上限，也不能因为预算到期就称为收敛。

## 产品目标与评价边界

最终任务是编谱：结合音频、难度、玩法和谱面上下文，选择取音、组织节奏和键型。单起音的逐事件匹配只用于受控基础检查。复杂音频存在多种合理编排，参考谱是一个条件分布样本，不是必须逐音符复刻的唯一答案；不能用起点 F1 代替音乐表达、模式和手感评价。

保留 Tap / Drag / Hold / Flick，不设 Hold 配额，不默认限制双指。4K、静态 free-x 分开记录，动态表演后置。节拍内 0/4/8/16/24/32 ticks 继续仅作匹配加分，不吸附、不强排、不把其他位置判错。

## 数学任务

固定 T=10 秒，采样率 f_s，波形 X={x[n]}，物理时间 t_n=n/f_s。谱面为 Y={(t_i,B_i)}，B_i={(k_ij,p_ij,d_ij)} 是同起点音符集合；k 为四键型，p 为轨道或连续横坐标，d 为 Hold 时长。c 为玩法与目标难度，风格控制需要真实标签支持。

令 S={t_i} 为谱面 skeleton、B={B_i} 为动作编排、H=E_theta(X) 为声学特征：

    p_theta(Y | X,c) = p_theta(S | H,c) p_theta(B | S,H,c)

分解用于明确责任，可以在同一 diffusion 网络内联合生成。声学起音 O 和谱面起点 S 是不同变量：自然音乐允许省略声音，并围绕节拍、持续音和乐句安排动作。起音是软证据，不是所有出键的硬门槛。

## 定长单起音基线

输入包括 10 秒真实静音、随机位置单钢琴音，以及音高/音色/音量/衰减变化；覆盖开头、末尾、特征帧边界。受控合约明确规定一个声音对应一个测试 Tap，静音为空谱，仅用于定位与数量检查。模型不获知目标数量，四键型产品接口保留。

暂定数值格 Delta=10ms、K=1000；每格预测起点概率 a_k 和连续偏移 r_k in [0,1)，还原 t_hat=(k+r_k)Delta。它是数值坐标，不是节拍网格。模型允许输出多个错误起点，不能用单音数量上限伪装数量控制成功。

    L_locate = sum_k BCE(a_k,y_k)
             + lambda_t sum_{k:y_k=1} Huber(r_hat_k-r*_k)

第一项同时处罚漏音和额外起点；第二项只监督真实起点的格内位置。静音的全部 y_k=0，仍参与训练。权重和阈值在开发阶段固定，不通过事后提高阈值删弱音。

进入密集音乐前审计同格碰撞，必要时增加格内事件槽并固定协议，不能覆盖/删标签。10ms 输出分辨率不意味着声学特征已具备 10ms 定位精度。

## 数学变量与网络结构

| 变量/操作 | 结构 | 验证问题 |
| --- | --- | --- |
| X -> A | 波形处理、Mel、物理帧时间戳 | 弱音是否保留，是否偏时/倍速 |
| A -> H_j | 卷积、双向音频 self-attention | 局部声音和全局段落能否表达 |
| t_k | 物理时间位置编码/时间 query | 网络是否知道正在判断的时刻 |
| t_k,H -> G_k | 全局 audio cross-attention | 当前局部证据与远处段落关系 |
| G_k -> a_k,r_k | 起点分类头、连续偏移头 | 是否出音、在哪里出音 |
| 谱面 token 关系 | diffusion 双向 self-attention | 重复、交互、楼梯、呼应 |
| k,p,d | 四分类、位置、时长输出 | 动作的具体实现 |
| c | 条件 embedding | 难度/玩法的控制效果 |
| s | diffusion noise-level embedding | 去噪程度，与音乐时间 t 区分 |

当前音频编码器已有 self-attention，先探测现有特征，不预先重写。

    alpha_kj = softmax_j(q_k^T W_K H_j / sqrt(d) + b_theta(t_k-tau_j))
    G_k = sum_j alpha_kj W_V H_j

tau_j 为音频 token 实际秒数。先以 b=0 建立基线，再单独比较可学习相对时间偏置；不加硬局部窗口。注意力图集中不等于对齐，必须用音频平移后的输出响应验证。

## 定位与 diffusion 的隔离对照

先用轻量定位头检查音频特征可读性，它是诊断基线，不承担完整编谱。随后使用相同目标的固定长度张量 Z_0=C(Y)，先验证 C^-1(C(Y))=Y。先含起点存在性/偏移，再加入四键型、位置、时长，空位置明确编码。

    Z_s = sqrt(alpha_bar_s) Z_0 + sqrt(1-alpha_bar_s) epsilon
    epsilon_hat = D_psi(Z_s,s,H,c)
    L_diff = E ||epsilon-epsilon_hat||^2

s 是扩散步，Z 的时间轴始终对应同一段 10 秒音频。首个小任务直接在目标张量扩散，暂不经过 VAE；历史 VAE 单列真值编码/重建检查，再比较引入 VAE 的影响。固定 T 的空白尾部由空位置表示，暂不用 EOS；取消 EOS 的工程失败不等于学会停止。

架构参考：[DiT](https://arxiv.org/abs/2212.09748)。这是本项目针对事件表示的适配计划，不是已执行复现。

## 逐级实验

| 阶段 | 增加的困难 | 归因与通过依据 |
| --- | --- | --- |
| E0 | 时间与表示 | 波形/特征/张量/导出无偏移、倍速、截断；编解码无损，时间往返建议 <1ms |
| E1 | 单起音、随机位置/音色/音量、静音 | 特征可读、准确定位、无多余起点；先拟合 32 个小样本，再扩展随机组合 |
| E2 | 0/1/2/3/5 起音、重复、弱音、长间隔 | 受控任务准确计数/定位，现有三音探针全部通过 |
| E3 | 长衰减、持续音、和弦、多乐器 | 分辨重新起音/持续/多声部；声学理解单评，不规定每个声音都出键 |
| E4 | 现有音乐固定 10 秒、难度条件 | 合理取音、密度与音乐支撑；不以参考谱逐音符匹配验收 |
| E5 | 相同音乐不同前缀、重复与模进 | 受控模式续写正确，自然编排连贯，能换段转换模式 |
| E6 | 20/40 秒、整曲、静态 free-x | 长上下文、边界、空间能力不退步，再做 Phira 试玩 |

E1 扩展合成集可暂定 P/R@25ms 均 >=99%、静音误出音为 0；这只是待冻结的受控实验门槛，不是自然音乐准确率承诺。固定 benchmark 波形不入训；优先解决训练样本拟合，少量固定合成复核样例仅检查是否记住固定起点，不急于扩大新歌测试。

复杂音乐编谱评估：

- 同音频不同难度应有不同但有音乐依据的密度/动作组合，不能只随机加键。主旋律、鼓组、重音、节拍、持续段均可作为编排依据。
- 相同音乐给短纵/交互/楼梯等不同前缀，在受控续写任务中检查历史使用；自然曲允许结束/切换模式。
- 重复/模进段应有可感知呼应，可改变位置与强度，不要求逐键复制。
- 四键型用分类目标；Hold 时长独立监督，不把衰减尾巴直接当 Hold 真值。
- 自动报告密度、模式关系、时间覆盖与异常；人工对照评音乐表达/手感，不由程序填写。
- 4K 先验证模式，free-x 再验证归一化坐标、反归一化和几何关系；无默认双指限制。

## 失败触发的单因素改进

| 现象 | 动作 |
| --- | --- |
| 真值编解码已丢音/偏时 | 修时间表示/编解码，停生成器训练 |
| 小样本定位器不能拟合 | 查标签/时戳/梯度/优化，再比较冻结/解冻编码器 |
| 定位器能定位但 diffusion 不能生成 | 查目标表示、稀疏事件学习、采样，不同时换前端 |
| 无 VAE 通过，加入 VAE 退步 | 修 VAE 事件重建 |
| 音频平移输出不跟随 | 查条件使用/时间编码，再比较时间偏置 |
| 起点合理但换前缀模式不变 | 查上下文训练/self-attention，不追键型配额 |
| 多种合理编排被回归成平均值 | 查条件区分与多模态生成 |
| 小任务通过、复杂训练未拟合 | 先查收敛，再分别增加预算或容量 |

同结构对照固定初始化、样本顺序、采样；关键结论多 seed。跨架构记录参数量、数据曝光、GPU 时长，不把各训 10 轮当公平或充分。历史三月 diffusion 只读保留；修正时基后另列训练/推理实验，不能把原权重推理改时轴后冒充同分布结论。

## 当前用户决定：先续训旧模型

不启动上述新结构实验。先恢复最新 4K absolute-time AR 的 audio / soft 两组 epoch-10 权重、AdamW 状态、样本顺序 RNG 和 torch RNG，使用相同全量 300 首及既有平移/静音样本。保持网络、损失、缓存、类型/时间策略与采样规则不变。

初始续训沿用 parent 末步学习率（约 3e-5），不重新随机初始化或重新 warmup。检查点按累计 epoch 记录，允许训练集过拟合，不用新歌验证损失触发早停。分开报告真实历史损失和训练曲自由生成、停止、键型模式、探针误出音。声学前端仍冻结，结论范围是当前特征/数据/目标下的解码器拟合能力，不宣称理论架构上限。

不能以一个固定轮数宣告充分；分段续训、定期生成，观察训练目标与出谱曲线。持续改善则继续；平台需记录观察窗口和优化条件，预算用尽只能写未收敛。不同优化设置（如后续调学习率、dropout）必须另列阶段，不能暗改。

保留原始 10 轮权重。新运行复用缓存，控制 latest/最佳训练损失/最佳生成 checkpoint 数量，保留小型评测记录，沿用磁盘/RAM/GPU 保护，不复制数据、不新增长期分支或 worktree。

## 2026-10-24：真实历史、生成历史与双向补谱的论文复核

用户提出是否需要用前后谱面预测中间段。以下研究讨论发生于 `AL-AR4K v0.5.1 / E14` 的300→500轮续训期间，未改变当轮配方。随后用户授权原配方延长至700轮，两组已于2026-10-24完成，见[700轮收尾](evaluations/ar_saturation_20261023.md#700轮收尾)：排布损失与总目标仍下降，自主生成仍不稳定，尚未证明达到架构上限。原数学计划保留，下列新训练方案均未执行，700轮后未自动加训。

当前代码在真实谱面token、时间及派生历史上做teacher forcing，推理则逐步使用自身生成的这些状态；不是只看前一个音符。全局cross-attention已经能看到未来音频，未来谱面尚未知。第320轮两组三首曲真实历史下帧准确率100%、末尾停止概率至少84.71%，12次自然曲自由生成仍全部尾部失败，支持进一步检查历史分布差距，但不证明唯一原因。排布拟合、时间推进、终止监督和实现一致性仍需分别归因。

“键型历史/时间历史”仅指诊断时区分同一谱面序列的字段，不是两套独立状态或网络。实际输入为token嵌入＋时间编码＋28维历史摘要的线性投影，融合后进入同一解码器；因果self-attention也访问过去的token。历史摘要含位置、类型、间隔和重复/交互统计。一步对应谱面token，不是固定音频帧，同一时刻可有多个token。任何受控替换都须保持语法与时间合法并重算一致的派生摘要。

用户进一步质疑人工摘要是否必要：self-attention本来可以学习历史关系，28维摘要只是提供预先计算的统计，不是Transformer的必需组件。其是否加快拟合、是否导致依赖仍未证实；当前A/S都包含摘要，早期短试也不能替代充分训练的消融。后续候选为“token＋时间/节拍条件”与“相同输入＋人工摘要”两组匹配初始化、数据和预算的独立充分训练。摘要中的间隔以BPM归一化，须保持两组获得的时间/节拍信息可比，避免同时改变是否知道BPM。只在现有权重推理时清零摘要可测依赖，但不得冒充不带摘要的重训结果。此项仍未执行，本轮500轮不改结构。

令A为全段音频，Y为谱面事件/token：常规AR拟合 `p(y_i | A,y*_<i)`，推理条件变成生成的历史 `yhat_<i`；FIM拟合的则是 `p(Y_middle | A,Y_prefix,Y_suffix)`。后者需要在使用时有可见的两侧谱面，不能只在训练时给真实后段，就宣称解决从音频独立生成。

| 一手论文 | 可借鉴方法 | 适用边界 |
| --- | --- | --- |
| [FIM，2022](https://arxiv.org/abs/2207.14255) | 前段/后段/中段重排，因果Transformer也能补中间 | 可做局部补谱或草稿修订；我们的时间指针、Hold状态和历史特征依赖时间顺序，不能直接重排现有token就认为适配完成 |
| [GKD，2024版本](https://arxiv.org/abs/2306.13649) | 在学生自己生成的前缀上查询教师分布并训练 | 仅保留文献参考；用户已明确不开展蒸馏，当前没有可靠编谱教师，不能把真实历史拟合好的AR或三月diffusion直接当作GKD教师 |
| [Scheduled Sampling for Transformers，2019](https://aclanthology.org/P19-2049/) | 两次解码，混合真实与预测历史 | 论文实验接近teacher-forcing基线，不能保证收益；生成时间变化后必须重新判断监督目标是否有效 |
| [Multi-token Prediction，2024](https://arxiv.org/abs/2404.19737) | 共享主干，增加多步预测监督 | 可测试连续键型关系；不等于使用生成历史训练，也不保证解决不结束 |
| [BART，2020](https://aclanthology.org/2020.acl-main.703/) | 双向读取被破坏的序列，再自回归恢复 | 对应草稿修谱；若只在干净参考谱上挖洞，仍需检查能否处理真实模型草稿的错误 |
| [LLaDA，2025](https://arxiv.org/abs/2502.09992) | 随机mask和反向恢复，建模双侧上下文 | 双向生成的架构参考，不是当前AR的低成本等价修复，也不能据文本结果保证编谱优于AR |

保留反证与方法限制：[Exposure Bias versus Self-Recovery，EMNLP 2021](https://arxiv.org/abs/1905.10617)发现其开放式文本设置中的前缀偏差影响有限，并有自恢复现象，不能把所有AR质量问题都归结为teacher forcing。[Huszár，2015](https://arxiv.org/abs/1511.05101)分析了朴素scheduled sampling目标的不一致性。训练中换了历史而机械保留原“下一个token”，并非总有正确的监督含义。

待本轮完成后按单因素推进，仍需依据诊断决定具体改动：

1. 固定同一检查点、音频与解码设置，分别检查只改变键型/轨道历史、只改变时间历史、两者共同自由推进；显式历史特征须与所给历史一致，不能暗留真值。比较4/16/64个事件后的定位偏差、误出音和停止行为，区分短段截断与模型主动结束；已有的真实历史整曲评测作为基线。
2. 若生成历史导致明显退化，先做有可验证标签的短程恢复训练。模型跳时、漏组或改变Hold状态时，不能直接复制原序号的下一键；先在受控探针和可对齐训练片段检验重标注，不把一份参考谱当作复杂音乐唯一正确编排。
3. 双向FIM/修谱另作对照：明确后段来自真实已知谱面、用户保留内容还是模型草稿；独立生成验收不得提供参考未来谱面。多步预测与历史训练也分开测试，避免同时换结构、损失和推理。

评测继续使用现有F1/网格加分，但另外必须报告完整生成、尾段覆盖、静音误出音和模式条件响应；网格只加分，四键型不设配额。上述路线尚未登记为新训练模型或宣称实现有效。

## 多步预测、段落损失与分块生成（讨论，未执行）

用户提出先生成一批帧，再计算整批损失。当前E14每次参数更新已汇总整曲、两个短段与静音的损失，每个序列内各位置并行使用真实前缀；不是每次只算一帧。自主生成当前只用于评测，没有进入训练目标。批量累计teacher-forced损失与在自主生成轨迹上训练应分开描述。

- 多步预测：[MTP](https://arxiv.org/abs/2404.19737)从同一前缀监督多个后续token，可作较小改动的模式学习对照；不等于短程自主生成。
- 序列级训练：[MRT](https://aclanthology.org/P16-1159/)、[MIXER](https://arxiv.org/abs/1511.06732)使用生成序列的整体评价调整模型，无需蒸馏教师。若先验证当前AR训练方式，候选为4/8/16个音符组的短程生成，保留监督基线并明确定位、误出音、模式和段落覆盖的评价。离散采样不可直接反传，且当前模型混合离散token/时间帧与连续偏移；实施前须定义各分支的有效梯度路径，不能对导出谱算F1后直接调用backward。
- 分块生成：[Block Diffusion，2025](https://arxiv.org/abs/2503.09573)以块间AR、块内联合去噪建模多位置关系。它是较大架构对照，块间仍有历史分布问题，不能保证自然解决结束；与现有定长diffusion归因计划保持接口与时基可比。

单步条件分解本身能表达整段联合分布，不据当前结果断言AR只能学习局部。若引入序列级评价，不能只优化F1或网格：360轮S/Eltaw虽然F1=0.83735，末键仍提前6.68秒。受控探针可严格约束数量/定位，自然复杂音乐仍不把一份参考谱逐键匹配当作唯一正确编排。本轮500轮保持原训练，以上均是后续待决定的独立实验。

## 优化困难与论文适用范围（讨论，未执行）

Transformer原始论文为[Attention Is All You Need，2017](https://arxiv.org/abs/1706.03762)。用户要求方案更多依据现代LLM/Transformer：旧非凸优化、RNN序列训练论文可解释机制，不能冒充当前结构已验证的效果；后续实现优先参考有Transformer实验与代码的MTP、Block Diffusion等工作。[Why Transformers Need Adam，NeurIPS 2024](https://arxiv.org/abs/2402.16788)提供参数模块曲率差异与优化器行为的证据，但不是本项目陷入局部最优的证明。

当前尚未做多初始化、学习率对照或损失曲率诊断，不能将F1波动归因为局部最优。损失持续下降既不保证最终达到全局最优，也不支持“已经卡死”的断言；真实历史训练目标与自主生成/音乐性目标不同，二者改善未必同步。结构、目标与优化因素要分别检验，本轮AdamW和学习率保持不变。
