## 2026-10-17：共享解码器的有效音频边界

设计 agent 审计旧条件实验时发现：局部 cross-attention 窗口完全落在有效音频外时，回退位置只钳位到 memory 张量边界，可能重新开放补零帧。主会话在独立 `fix/decoder-valid-memory` 分支复现并修复，提交 `5a6877a`。现在按每个样本的有效掩码选择最近帧，支持内部空洞，距离相同取较早帧；空 memory 或完全没有有效音频帧时明确报错。非空局部窗口的规则保持。

修复前七项边界／不变性回归失败，包括改变无效 memory 内容会改变定轨和 64-bin free-x 的输出；修复后模型、free-x token 和产品流程定向回归 **43 passed**。设计 agent 独立复验解码器 **25 passed**，涵盖全前向与增量 step 一致、前后越界、内部空洞、不同批样本及小数时刻。合入后主会话完整回归为 **249 passed，9 warnings，35.19 秒**，全部使用 CPU 两线程。

该修复只约束解码器读取的 memory，不修复编码器先看补零造成的特征变化，也不重新认证旧权重或旧实验。当前产品整曲布局没有此处的 padding 回退示例；未因此重复整曲 GPU 生成或声称模型质量提高。旧条件实验的可复用部分与后续修正见 [音频条件审计说明](conditioning_audit_review.md)。
