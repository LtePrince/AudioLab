# 模型优化：先定位骨架与图案问题

状态：2026-10-22。按用户的 `AudioLab-update-plan.md` 开始新一轮设计／开发协作；核对基线为 `develop@b9cd3af`。O1 已在 `1192ae6` 完成12份谱诊断并通过独立审查，下一步是一首×两路线的正常／零声学特征自由采样，补齐 teacher forcing 的证据边界。首版仍为 Phira 触屏四固定位置 4K 与静态 free-x，四键型、多指和 Hold 无数量配额保持；动态演出、编辑、DPO／RL 不进入本批。

计划来源文件位于仓库外 `Audio/AudioLab-update-plan.md`，SHA256 为 `7be4d13e97f167cc1799d9a593fa3c015acb2f548c75be6743a8e58a2a40ec47`。其内容包括用户观察和明确标为一般经验推断的 AI 建议；不能把后者当成已验证结论。本文件把可执行范围、分母和继续条件固定下来，结果另存评估文档。已有 [C2 条件诊断](evaluations/audio_conditioning_v2.md)和 [R1 Hold 规则对照](evaluations/hold_repair_v1.md)继续有效，不重新跑相同实验。

## 代码事实与待验证解释

| 计划中的说法 | 当前核对 | 本轮怎么处理 |
| --- | --- | --- |
| 时间完全受 skeleton 限制 | 在产品混合生成路径中成立：每个入选 tick 至少一个 NOTE，不能跳过或新增未提供的起点；键型、押数、位置和持续由布局模型采样 | 核对候选→量化／合并→原始／最终谱的唯一起点覆盖；保留失败分母 |
| 没有弱起音表达 | 需区分低置信度候选、低声能事件、弱拍／乐句弱起。后两者没有标签；被选入的弱起时刻可以生成，不能由强制覆盖推出其不存在 | 只称“未校准取音分数”和“选择／遗漏”；本批不报告声学召回或弱拍识别率 |
| skeleton 应进入网络 | 当前不是独立条件张量，但强制的 DT 历史与 `tok_frames` 已提供所走时间；并非网络完全不知道时间 | 独立 skeleton 编码、候选置信度／跳过动作属于后续表示实验，先定位缺失信息 |
| free-x 偏移不参与自回归 | 成立：在当前 NOTE hidden 上回归 residual，输出后未作为后续 token 输入；64 bin 的位置符号仍在历史中 | 对已有输出做 bin 中心反事实，量化 residual 对指定图案几何的影响；不是生成消融，也不能证明因果 |
| `factorized` 解决类型×位置稀疏 | 它分解 NOTE **输入嵌入**；输出仍为完整词表线性头。稀疏程度、收益尚需数据 | 不直接声称大量组合欠训练，也不先扩大模型 |
| 规则保证合法 | GrammarState 保证部分 token 语法及同 tick 不重复 lane/bin；并不证明所有触摸动作合理 | 格式、几何描述、Phira 判定与真人反馈分开；相邻 bin 的 residual 仍可能让实际 x 很接近 |
| free-x 变形来自表示 | 有合理机制，但尚未隔离 token 位置选择、residual、源谱静态投影、bin 去重和后处理的贡献 | 源参考／codec 保留／raw／final 分层，先测量，不把规则吸附直接当模型改善 |
| 模型太小、无轨数据更少、4K 已学好 | 当前计划没有支持这些比较的实验证据 | 不据此启动大模型、4K 迁移或大训练 |

代码入口：`src/models/chart_decoder.py`、`src/data/chart_tokenizer.py`、`src/audio_understanding/inference.py`、`src/product/pipeline.py`。free-x 区间为屏宽归一坐标 `[0.05, 0.95]`，64 bin，bin 宽 `0.9/64`；源数据在相同 tick/bin 下只保留首个音符，短于一 tick 的 Hold 可变为 Tap。这些表示损失与模型采样错误分别记录。

## O1：本批 CPU 诊断

输入固定为已有手填／自动时基三曲×两玩法的12份 raw/final 产物，以及 C2 使用的同三曲参考。它们反复用于开发，不是未见测试集；手填与自动时基是两个已存在条件，不将其间差异只归因于模型。逐曲保留源路径与哈希、代码版本、实际配置、音符／起点／候选／窗口分母、未支持与失败项。复用既有 provenance，不另建审计平台，不加载模型、复制音频或重算整库特征。

| 部分 | 固定定义与输出 | 不支持的结论 |
| --- | --- | --- |
| 候选覆盖 | 按各谱自己的整数 tick 分组。列原候选数、量化合并／边界钳制、唯一 tick 数、raw/final 起点数、缺失／新增 tick 与每个候选的音符数。保留音频秒和编码 BPM／offset，避免跨时基直接比 tick | 100% 覆盖不是取音准确率；候选分数不是校准的声学概率 |
| 候选选择证据 | 读取已保存候选的分数与选择配置；阈值前分数未保留就写 unavailable | 不能从已入选候选反推出被筛掉多少真音乐事件，或把低分一概称弱起 |
| 固定窗口 | 取全局连续四个 onset 组；四组都为 singleton 才进入类型描述，不能跳过和弦拼出序列。以 lane/bin 判定 AAAA 重复、ABAB 交互（A≠B）、严格单调位置序列；其余为 unclassified。窗口允许重叠，分别报全部窗口、合格窗口与分类数量 | 不是完整图案字典；严格单调只称 monotonic_run，不直接认定为人工楼梯设计 |
| 节律 | 每个合格实例记录三个相邻起点间隔及间隔离散度，单位为音频秒；与空间类别分开，不为凑数量加等间隔筛选 | 编码 BPM 不是已标注真拍；规则性越高不代表越好 |
| 4K | 报离散位置重复／交互／单调实例、同刻组合、raw→final 的实例变化；四键型分别保留，不设押数上限 | 不能仅凭这些实例多就说定轨模型更好，不能用不同词表的 NLL 跨模式排名 |
| free-x | 在上述已识别实例中测实际连续 x：AAAA 的复现离散度、ABAB 相同角色复现偏差、单调序列相邻步长离散度。冻结 raw 实例 ID，配对查看 final，不因修复后分类改变而重选改善实例 | 不是全谱对齐率、对称率或几何质量分数；未分类实例仍计入分母 |
| 同刻组合 | 两模式分别报押数；free-x 记录 sorted x、span、相邻 gap，≥3 点时可列等间距残差。重复形状比较只在明确相同基数的实例中进行 | 不预设同拍音符必须对称或等距，不自动吸附 |
| 表示反事实 | free-x 保持全部音符头时间／键型／持续／bin，令 residual=0.5；仅重算同一实例的几何量，记最大实际位移和变化分布，不导出产品默认 | 不是真正重新生成；更小残差可由定义直接导致，不能当成更好听／更好玩 |
| 参考谱 | 保留源音符与 codec 去重后分母，使用相同描述器；列出原谱投影和量化带来的损失 | 人工谱是有效编排之一，不是唯一答案或声学真值；不追齐其 Hold／pattern 比例 |

每个几何量给出公式、坐标单位和零分母处理；只有量纲相同的实例可汇总。数值容差用于浮点一致性，不新增产品阈值。最多保留少量可定位实例与完整摘要，输出预算10 MiB；资源保护和8 GiB余盘继续生效。CPU 测试覆盖已知四类／未分类、和弦隔断、非均匀节律、residual 只改变连续几何、raw/final 稳定 ID 配对，以及空分母。失败报告不能写成功标记。

O1 验收是工具能正确描述这批谱，不是模型质量通过。设计 agent 以固定提交独立检查手算夹具、真实摘要及几个有区分度的实例；无需重新逐文件审计已经核对过的全部 C2／R1 产物。

### O1 固定结果与独立审查

实现 `chore/pattern-diagnostics@1192ae6` 的27项专项由设计 agent 独立通过（2.68秒）。真实报告为 `AudioLab-pattern-diagnostics/out/pattern_diagnostics_v1/report.json`，SHA256 `89d45033e25c230b5852a3fbdef81645c4574d5d9433884456c8c2d9532e550d`；固定源码、工作树干净，12／12完成并引用6份路线参考，耗时2.169秒、峰RSS0.624 GiB、输出1,760,911字节。已有 NPZ 确实保存阈值前数组，本轮仅读取三个小数组复现选择，没有加载保存的 features 或重新推理。

| 观察 | 结果与解释边界 |
| --- | --- |
| 骨架覆盖 | 三曲有效帧2213／3103／3850，分数≥0.7的帧597／750／1215，NMS或重复时间去除50／36／80，最终候选547／714／1135。12谱的 raw/final 均覆盖其全部候选，本批量化合并／钳制均为0。帧分母不能当真实音乐事件分母 |
| 位置后处理 | 4K无位置移动；free-x共8个音符移动，涉及4个和弦。已识别连续 singleton 实例的几何均未被修复改变，因此不能把这部分图案问题归因于当前空间后处理 |
| residual 中心 | 本批单音最大移动约0.007029屏宽，数学上限0.00703125。重复／交互的同 bin 偏差归零是定义导致的结果；不能由此认定换中心更好，也不能把全部离散结构差异归因于 residual |
| 分母限制 | 手填与自动时基影响音符数、和弦和 singleton 窗口数；有限描述器中有大量 unclassified。类别更少不等于没有人工设计，类别更多也不证明更好 |
| Hold | 4K／free-x分别2／63次持续截短与已有R1一致，不新增数量目标或重复计算其音乐收益 |

独立标准库检查核对了12行选择／窗口／押数分母、6份参考及报告字节数，并从4份源 raw JSON 独立重算分类和和弦隔断数，全部一致；耗时0.071秒。选取手填第一曲两路线、手填第二曲 free-x、自动第三曲 free-x，覆盖两种时基、位置移动和较多重复实例。证据位于本设计 worktree 的 `out/optimization_review/pattern_diagnostics_v1_review.json`。失败写入残留完成文件与几何零分母两个草稿问题已修复并由专项覆盖；没有未解决的 O1 工程阻塞。

工具公式与复现命令见[固定实现说明](https://github.com/LtePrince/AudioLab/blob/1192ae6/docs/pattern_diagnostics.md)。O1 关闭的是这批工具与产物验收，模型质量、另一PC运行状态和Phira真机反馈不因此改变。

## 音频依赖：复用 C2，补齐其不能回答的问题

C2 已固定 `0580ab4` 的三曲、两模型、四种 encoded-feature 条件，报告 SHA256 为 `26de0aa70abef8772ee45f15c251cf929275aa34ce7b095a53a21c38b1092114`。匹配特征总体 token bits 较低，但 free-x 的位置、持续和 offset 有反向分项；这只说明真实参考历史下的有限条件敏感性。O1 引用其逐项结果，不重跑，也不把特征反排称为真实倒放音频。

接下来若需检查自由采样，先在一首已用开发曲上固定候选、时基、完整 encoder、模型、seed、temperature／top_p、自然 EOS 与资源限制，只替换布局特征；正确特征与一种已声明负对照构成首轮。记录音符、键型、持续、pattern 和修复的逐项变化，并保留听看对照。结果变化只能证明敏感，音乐对应改善仍需可听辨片段或明确标签。由主会话排队 GPU，小样例有价值才扩曲目／seed，不与 skeleton 选择实验混在同一对照。

O1 之后先执行这个有限对照：沿用手填第一曲102.770秒音频、188编码BPM、offset=0、seed=42、temperature=1、top_p=0.95、完整布局编码与相同候选，两路线各比较 `matched` 和 `zero_acoustic_features`。zero 在 `prepare_memory` **之前**作用于声学特征，保留时间嵌入、投影偏置、有效 mask 和固定候选；后续历史是各条件自己采样的历史。不能照搬 C2 的“真实参考历史”说明，也不能把它称为完全无条件。先以正常分支核对旧基线行为，再解释负对照差异；产品默认、模型权重和 skeleton 选择保持。

## O2：看完 O1 后只选一个低成本因素

1. **骨架取舍优先候选。** 如果覆盖报告确认强制选择是主要待查点，复用已存分数做少量显式 selector 条件，记录保留／删除／合并候选 ID；再生成时保持布局条件不变并要求自然完成。阈值只定义实验，不自动替换产品阈值；不能用更稀疏或更接近官谱音符数宣称更好。若目标是低分的声音弱起，先给出可听辨片段，避免把它删掉作为“修复”。
2. **free-x 几何优先候选。** 若同 bin／同角色复现的误差主要来自 residual，先在少量实例形成原始与有限几何候选供听看；若 bin 选择本身已经改变结构，则先调整采样或输入表示，不用全谱吸附掩盖。4K 与 free-x 独立报告。是否改善由具体设计与音乐关系决定，不能直接最小化所有间距偏差。
3. **N-best 后置于可用评价。** 先有能够区分具体好坏片段的规则或人类偏好，再从 N=2 的有限试验开始；固定时基与采样条件，记录额外耗时、失败及选择理由。未验证的“对齐＋对称越多越好”不能作为 rerank 奖励。

O2 的实现由开发 agent 提议、设计 agent 审查、主会话协调资源；这一常规实验不需要再问用户许可。每批只改变一个因素，保留 baseline 与可恢复配置；通过时间／格式检查不自动切换默认。真实 Phira 试玩与人工音乐判断仍未补齐，不能由描述器或规则奖励代填。

## 后续表示与训练，按路线分别推进

| 路线 | 有证据后的小实验 | 进入条件 |
| --- | --- | --- |
| 共享取音／音频理解 | 候选置信度与可跳过动作；sustain／downbeat／section 的独立监督或预训练特征；混音与分离声源对照 | 先明确标签、时钟与误差，区分声音持续和 Hold 设计；不为本轮下载完整新数据集 |
| 4K | lane 历史、同刻组合和持续交互；有限镜像增强／有标签的 pattern 辅助任务 | 先确认具体失败实例与现有训练覆盖，保留四键型、多指与真实来源划分 |
| free-x | residual 入历史、相对位置／活跃 Hold 特征、相对几何辅助目标；再考虑结构→位置两层 | 先量化 bin 去重、投影、离散选择和 residual 的贡献；镜像／平移需记录裁剪及语义变化，不能把数据增强称为零训练成本 |
| 偏好优化 | 有效人工或已验证的比较标签后，才考虑 DPO／RL | 奖励与实际音乐／触屏体验有一致证据，防止模型靠密度、对齐或 Hold 数量投机 |

当前文档分支 `docs/model-optimization-plan`、共享诊断实现分支 `chore/pattern-diagnostics`；未来模型修改分别进入 `feature/4k-generation` 与 `feature/freeform-gameplay`，共享音频修改独立提交。验证后推对应分支并集成 develop；main 的真实试玩和模型质量门槛保持。
