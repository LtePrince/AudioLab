# 因果历史状态实验

`src/models/chart_history.py` 提供28维、只依赖已生成前缀的状态输入：前两个音符
的位置与位移、拍间隔、同刻组合、最近四组位置，以及重复／交互／单调序列长度。
4K 使用 lane/3；free-x 使用 (bin+residual)/64，表示可玩水平区间内的相对坐标。
最多保留64个起点组；和弦打断 singleton 模式，不越过和弦拼接图案。

训练与逐步生成共用状态机。当前输入 token 的 forward **之前**读状态，预测其
连续 offset **之后**再 observe；因此该 offset 只能影响下一 token。训练使用
此前参考音符，推理使用此前实际生成音符。不能把当前 offset 真值送入其自己的
回归头。Hold duration 链没有解完时不提供未来终点；本版没有活跃Hold终点特征。

这些特征是可学习的条件，不产生强制连打／交互／楼梯，也不改变 grammar 掩码。
模块7项CPU测试覆盖模式长度、和弦中断、连续坐标延迟反馈、未来信息隔离，以及
整序列和逐步状态一致。实际收益须由同训练预算的接入实验验证，模块测试不代表
生成图案已改善。先完成soft-onset对照，再以相同初始化／步数增加history条件；
模式辅助监督单列后续实验，不与第一项同时改变。
