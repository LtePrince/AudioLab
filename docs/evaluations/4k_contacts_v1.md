## 使用与复现

生成时传 `--playability-profile contacts-v1`，4K 不传 `--max-contacts`。
生成批次使用新的输出目录，避免复用不同配置的旧文件。
```bash
.venv/bin/python -m script.evaluate_contacts --model decoder \
  --output out/contact_profiles_nms35_4k_val30
```

该命令要求新目录。完整报告和谱面位于 `out/contact_profiles_nms35_4k_val30/`，
`playtest_manifest.json` 包含最差/中位/最佳 F1 及改动较多曲目的谱面与现有音频路径。
不复制音频，不提交数据、模型、生成谱面到 Git。
