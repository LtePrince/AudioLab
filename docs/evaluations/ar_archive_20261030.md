## 校验与恢复

逐个核对原文件 SHA256、快照旁文件、评测所用完整断点 SHA 和 ZIP 成员 SHA；上传后核对 GitHub 附件大小及 SHA256 digest。完整断点与紧凑快照的文件 SHA 不同，使用旁文件的 `source_checkpoint_sha256` 追溯关系，不能把两者当作同一文件。[主清单](assets/ar_archive_20261030/manifest.json)、[补充清单](assets/ar_archive_20261030/supplementary-manifest.json)、[远端附件及哈希](assets/ar_archive_20261030/published.json)。

恢复紧凑快照时，下载对应 ZIP 并校验 Release 中的 `SHA256SUMS.txt`（1350 补充包对应 `SHA256SUMS-additional.txt`），从 AudioLab 根目录解压所需成员；ZIP 内保留仓库相对路径，原文件 SHA 见清单。需要续训时，下载对应 `resume_e1400.pt`，校验后放回清单中的 `resume.path`。不要用紧凑快照冒充包含优化器的完整断点。
