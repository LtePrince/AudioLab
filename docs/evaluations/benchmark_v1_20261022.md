本次基线只重放 `out/onset_attention_20261022` 的既有产物。6 个模型各有 greedy／seed42 两种输出，另有共享 onset 前端。每组布局应评 5 个构造例＋3 首训练曲，目前重复音和跨块两例缺输出，因此为 6/8；未执行 seeds 43/44。没有重新训练或生成音频。

三音失败与弱音遗漏仍保留，不能发布替换权重。4K local greedy、free-x global greedy 等在自然曲上的网格匹配接近 1，但起点 F1／空谱情况不同，说明网格奖励必须与音频对应和覆盖分开看。

公式、段落指标、模式标签、输入格式和复现命令见 [benchmark 规范](../model_benchmark.md)。音频质量和实际触屏评价仍待补充。

验证：76 项相关测试通过，另检查通用 JSON 重放及手写正确答案入口。完整结果与可迁移输入在 `out/benchmark_v1/report.json`、`inputs.json`，Git 保留本摘要和协议；原始音频、缓存和权重不入库。
