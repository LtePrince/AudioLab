# 第 2 阶段：W0 整曲输出与 W1 分窗输出

2026-10-31。**当前状态：受控训练进行中，尚未得到本阶段最终结论。** 两组从头训练，先检验协议与小样本学习能力；不是原四模型在 300 首歌曲上的新一轮长训。

## 模型改动与对照

W0 是原 `AnchoredAR`，6,626,691 参数；W1 是 `WindowedAR`，6,692,227 参数，增加 65,536 参数的窗口边界投影。两组初始主干 SHA256 完全一致：`8a4f75f2dcd41e7950df7680f59177883bbb755ac0f8fc6dbaa5d8bc4980e041`。W1 的额外投影初始化为零；训练开始前重新设定相同 dropout RNG。两组都是纯音频 A，S 尚未加入此对照。

W1 在每个输入 token 加入当前窗口 `[s,e)` 的两组物理时间正弦编码投影；time pointer 的候选区间改为 `max(s,上一组时间+ε) ≤ t < e`。停止头监督变为 END_WINDOW，随后调度到紧邻下一窗口。空窗合法，不要求每窗出音；同一参考起点只监督一次。Hold 按起点归属窗口，完整时长可超过窗口末端。

全曲原分辨率音频 memory、全因果历史、28 维历史摘要、四键型、NOTE 联合表示和原损失权重保持原配置。窗口边界不参与 cross-attention 遮罩。与 W0 相比，W1 改的是整套输出协议，包括边界条件、候选域及结束标签；不能把可能收益归因成仅仅加了 mask。

推理中若当前窗口耗尽合法时间但模型仍要继续，会记录 `forced_no_remaining_interval` 并继续检查后续窗口，整次结果标记失败。报告分别记录模型 END_WINDOW、调度遍历率与强制边界次数，不将调度走完整曲视为模型学会整曲 EOS。

## 实际训练配置

共用冻结数据 SHA256：`f08ecf395fec7dbd4f2beff403a087a9d3dd436beaf8de636892f7e3a72c4a6e`。32 条构造训练音频，时长 10/20/30/35 秒，含静音、单音、多音、多押、四键型及跨窗 Hold；另有 32 条独立随机组合和原 5 个固定起音探针。音色到类型/位置的确定映射用于检查可学习性，不代表自然音乐的编谱标准；固定旧探针只评起点，不使用其人为位置/类型标签评分。

两组各 400 轮、12,800 次更新，AdamW，峰值学习率 3e-4，同一 warmup/cosine 配方、种子 42 和样本顺序。每轮同样曝光 140 个起点组、324 个布局标签；W0 每轮 32 个停止标签，W1 为 80 个窗口结束标签。额外边界标签是协议变化的一部分，已单独计数。

GPU 0 为 W0，GPU 1 为 W1；每组仅保留最新完整断点和一个紧凑最佳拟合快照。100/200/300 轮先评固定 8 条训练样本；400 轮评全部训练样本、随机组合及旧探针。两组使用贪心，生成上限 512 token，耗尽预算按失败报告。不能把不同范围的均分直接当作训练曲线。

100、200 轮的 8 条训练样本上，两组起点 F1@25ms 和时间＋位置＋键型联合 F1 均为 1，全部完成；W1 未发生强制窗口结束。这只是中途受控拟合结果，全体样本和未入训组合结论需等最终评测。
