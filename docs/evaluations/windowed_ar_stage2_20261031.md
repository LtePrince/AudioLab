# 第 2 阶段：W0 整曲输出与 W1 分窗输出

2026-10-31。**当前状态：两组各 400 轮受控训练和完整诊断已完成；小样本可拟合，未入训组合未通过质量门槛。** 分窗改善了随机组合的平均起点匹配，却在固定三音探针上回退，暂不扩展成全 300 首的新一轮长训。以下是协议与小样本学习实验，不是产品模型的升级认证。

## 模型改动与对照

W0 是原 `AnchoredAR`，6,626,691 参数；W1 是 `WindowedAR`，6,692,227 参数，增加 65,536 参数的窗口边界投影。两组初始主干 SHA256 完全一致：`8a4f75f2dcd41e7950df7680f59177883bbb755ac0f8fc6dbaa5d8bc4980e041`。W1 的额外投影初始化为零；训练开始前重新设定相同 dropout RNG。两组都是纯音频 A，S 尚未加入此对照。

W1 在每个输入 token 加入当前窗口 `[s,e)` 的两组物理时间正弦编码投影；time pointer 的候选区间改为 `max(s,上一组时间+ε) ≤ t < e`。停止头监督变为 END_WINDOW，随后调度到紧邻下一窗口。空窗合法，不要求每窗出音；同一参考起点只监督一次。Hold 按起点归属窗口，完整时长可超过窗口末端。

全曲原分辨率音频 memory、全因果历史、28 维历史摘要、四键型、NOTE 联合表示和原损失权重保持原配置。窗口边界不参与 cross-attention 遮罩。与 W0 相比，W1 改的是整套输出协议，包括边界条件、候选域及结束标签；不能把可能收益归因成仅仅加了 mask。

推理中若当前窗口耗尽合法时间但模型仍要继续，会记录 `forced_no_remaining_interval` 并继续检查后续窗口，整次结果标记失败。报告分别记录模型 END_WINDOW、调度遍历率与强制边界次数，不将调度走完整曲视为模型学会整曲 EOS。

## 实际训练配置

共用冻结数据 SHA256：`f08ecf395fec7dbd4f2beff403a087a9d3dd436beaf8de636892f7e3a72c4a6e`。32 条构造训练音频，时长 10/20/30/35 秒，含静音、单音、多音、多押、四键型及跨窗 Hold；另有 32 条独立随机组合和原 5 个固定起音探针。音色到类型/位置的确定映射用于检查可学习性，不代表自然音乐的编谱标准；固定旧探针只评起点，不使用其人为位置/类型标签评分。

两组各 400 轮、12,800 次更新，AdamW，峰值学习率 3e-4，同一 warmup/cosine 配方、种子 42 和样本顺序。每轮同样曝光 140 个起点组、324 个布局标签；W0 每轮 32 个停止标签，W1 为 80 个窗口结束标签。额外边界标签是协议变化的一部分，已单独计数。

GPU 0 为 W0，GPU 1 为 W1；每组仅保留最新完整断点和一个紧凑最佳拟合快照。100/200/300 轮先评固定 8 条训练样本；400 轮评全部训练样本、随机组合及旧探针。两组使用贪心，生成上限 512 token，耗尽预算按失败报告。不能把不同范围的均分直接当作训练曲线。

100、200、300 轮固定 8 条训练样本均已完全拟合。400 轮全部 32 条训练样本，两组起点 F1@25ms、时间＋位置＋键型联合 F1 均为 1，全部正常完成；W1 未强制结束窗口。最终 teacher-forced 条件时间误差 W0/W1 为 0.194/0.118 ms。训练循环用时分别 747/790 秒（含中途评测，不含最终评测），峰值显存 allocated 0.141/0.143 GiB，进程 RSS 1.718/1.693 GiB；这些是缓存特征上的短音频诊断资源，不是整曲服务峰值。

## 生成效果与归因

F1 按正样本宏平均，静音单列；不能把静音的满分掺入起点均分。联合 F1 要求时间、轨道与键型都匹配，未正常完成的样本记零。所有数据均为原始输出，无吸附、起音门限、删音或补音。

| 400 轮检查 | W0 整曲输出 | W1 当前窗口输出 |
| --- | ---: | ---: |
| 训练 28 条非静音起点 F1@25ms | 1.0000 | 1.0000 |
| 独立随机组合 28 条非静音起点 F1@25ms | 0.4436 | 0.5472 |
| 同上时间＋位置＋键型 F1@25ms | 0.2840 | 0.3352 |
| 随机组合唯一起点微平均 P/R | 0.2197 / 0.5571 | 0.2100 / 0.5714 |
| 随机组合正常完成（含 4 条静音） | 30/32 | 29/32 |
| 原 4 条非静音固定探针起点 F1@25ms | 0.5000 | 0.3500 |
| 训练／随机／固定静音额外起点 | 0 / 0 / 0 | 0 / 0 / 0 |

两组 25/50 ms 的起点分相同，主要问题是漏组或额外组，而非恰好超出 25 ms 的微小偏差。W0 固定探针每条只输出 3 个参考中的 1 个；W1 的四条固定探针 F1 分别为 0.3333、0.1667、0.4000、0.5000。随机组合中也存在短区间重复大量出键。W1 遍历全部 80 个窗口，其中 77 个由模型 END_WINDOW 正常结束、3 个需要强制边界；调度走完不代表学会正确覆盖。

为区分正确历史下的泛化与自由生成的误差累积，额外输入随机组合的完整真实前缀，仅测下一步，结果如下。它是条件诊断，不是自由生成分数；固定探针没有可靠排布真值，未用人为 Tap 标签做此诊断。

| 真实前缀诊断（随机组合） | W0 | W1 |
| --- | ---: | ---: |
| 下一起点定位在 ±25 ms 内（先假设继续） | 64/140 = 45.71% | 80/140 = 57.14% |
| 正确继续且定位在 ±25 ms 内 | 57/140 = 40.71% | 69/140 = 49.29% |
| 仍有真值事件时误判结束 | 17/140 = 12.14% | 23/140 = 16.43% |
| 应结束时正确结束 | 13/32 = 40.63% | 55/80 = 68.75% |
| 真实前缀下布局 token 准确率 | 227/323 = 70.28% | 234/323 = 72.45% |

这排除了“所有错误都来自早期错误历史累积”的单一解释：即使前缀完全正确，时间定位仍只对约一半。与 D0 轻量定位器能读出固定三音相比，AR 在这些未入训组合上的条件映射泛化更弱；不能把它直接归因于冻结特征完全没有起音信息。32 条固定样本反复训练后全部拟合，说明继续相同数据的训练不能再用来证明训练样本欠拟合。数据覆盖、序列条件的使用方式和结束监督仍需分项实验，尚未证明哪个是唯一原因。

网格仍是加分统计：随机参考音符均匀取 32-tick 位置，并非只取偏好位置，其平均参考网格分 0.2024；W0/W1 原始输出网格为 0.2148/0.2366，不能以高于参考宣称更准确。固定探针参考为 1.0000，两组输出为 0.3825/0.4449；W1 网格略高却起点 F1 更低，说明只看网格会掩盖取音错误。

训练侧 3 个跨窗 Hold 均正确恢复；随机侧同样 3 个参考，W0 匹配 0 个、W1 匹配 2 个。已匹配 Hold 的时长编码正确，不代表所有 Hold 都被正确生成。完整结果、分母、逐例输出与复现脚本见 [诊断结果](assets/windowed_ar_20261031/w0_w1_controlled_result.json) 和 [汇总脚本](assets/windowed_ar_20261031/summarize_controlled.py)。

## 下一步及范围

窗口协议在训练集上可学习，限制输出责任区间的实现有效；新组合上的成谱质量未通过，因此本轮不宣布 W1 胜出，也不将它推到产品。下一步在这一受控环境单独检验历史时间扰动，保留同一 W1 无扰动对照；该实验只能检验小误差恢复，不声称能解决全部条件泛化问题。自然歌曲全 300 首训练、E20 缺音区间复测及实际 Phira 试玩仍待基础门槛通过。

## 已完成的实现检查

窗口/原 AR/原 free-x/续训/产品运行相关共 62 项测试通过。覆盖输入完整计算与缓存逐 token 一致性、未来谱面标签不可泄漏、窗口外音频依然影响当前隐藏状态、窗口条件有监督梯度、边界点半开归属、跨窗 Hold 不拆分、空窗，以及强制结束不伪装成正常模型结束。

另外对已有全 300 首 4K 标签执行 codec 审计：W1 去除新增边界 token 后与原 token 流逐项相等，215,174 个起点组均在对应窗口合法，float64 时间往返最大误差为 0；完整曲目 END_WINDOW 标签 4,462 个，旧整曲停止标签 300 个。这只是数据协议审计，**不是全 300 首新模型训练或成谱评测**。[审计证据](assets/windowed_ar_20261031/corpus_codec_audit.json)。
