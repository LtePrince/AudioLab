## 新增试玩反馈与本轮优先级

用户随后试玩文件夹中的旧 4K 谱，新增 **ELTAW-04**：前奏音乐基本是同一节奏的
重复或模进，但 4K 的键型／轨道模式没有体现这些关系。这里的“键型”包含连续动作
与位置编排，不能只检查 Tap／Drag／Hold／Flick 的数量。暂未标注精确乐句边界，
本条不凭空指定秒数，也不宣称新模型已修复。

优化证据应包含：相邻重复乐句的起点间隔是否相似、键型／轨道序列能否保留可感知的
动机；模进段落的相对方向／位置变化是否连贯。音乐本身的重复／模进需要听辨或可靠
的音乐标注，不能只看生成谱出现 AAAA／ABAB 的次数。网格匹配只覆盖拍内位置，
不能评价这种乐句到玩法模式的对应，也不应靠强制每段复制同一模式刷分。
