# E20：两首新歌段落缺音归因

2026-10-30，针对[居中两首的对照图](phira_mid_layout_20261030.md)，用同一冻结权重与前端复跑八份原始贪心输出，记录时间头概率，并检查被跳过段落的波形、音频特征、有效帧和导出行为。**八份音符列表及结束状态均逐项复现；没有训练或修改生成代码、权重。**

## 已确认的直接原因

当前模型先预测“下一个音符组在哪个音频帧”，再在那个时刻生成键型；不是逐帧决定“这一帧是否出键”。时间头允许选取当前时刻之后的任何有效音频帧。这里发生的是**把远处帧错选为下一事件，然后直接跳过整段**。

例如《匙ノ咒》4K A 在 89.884923 秒完成音符组后，给 253.329705 秒起始帧的原始 softmax 概率为 **0.910012**，给未来两秒的总概率为 **0.089515**；帧内回归后下一起点是 **253.372418 秒**。中间 163.487 秒没有 NOTE 生成步骤，也没有持续 Hold。它不是先生成再被导出删掉。

输出时间必须单调向前；这一跳后，时间头不再允许选回被跳过的帧。**全局 cross-attention 仍能看那些音频，但已无法在过去补键。** 这个输出时间约束与音频可见范围是两回事。

## 已排除什么

- 八个最大缺音段的平均波形 RMS 为 **−13.58 至 −9.92 dBFS**；按 100 ms 检查，没有低于 −60 dBFS 的块。被跳过的是有持续声音的段落。
- 对应音频特征全部有限、非零，所有帧 `valid=True`，没有被窗口或 padding mask 藏掉。软起音最大概率为 **0.9781–0.9897**，也没有整段归零。A 没有使用额外起音通道；S 虽然使用，仍可能错选远处时间。
- 八份原始/导出音符数完全相同，截断统计中的删音、缩短 Hold、不完整音符均为零。
- 八次大跳转时停止概率为 **5.4e−17 至 1.9e−10**：模型决定继续，然后选错位置，并非在段落开头触发停止。最终音频末尾停止失败是另一个问题。

这些检查排除了输入为空、特征缺失或被遮罩、导出删音；**没有证明前端已正确理解所有音乐事件**，也不意味着有声音就必须逐帧或逐音符出键。

## 两项上下文对照

第一项只在最大跳转决策处清空 self-attention 缓存，回放最近 64 个完全相同的 token、绝对时间、位置编号与历史摘要。全局音频和摘要不变，单独观察较远谱面上下文对时间选择的影响。这是诊断，不是新交付策略。

缩短谱面上下文后，三份回到未来一秒内，另几份仍有严重跳转。说明远处生成历史确实参与部分错误决策，但**仅截断历史不能统一解决**；本对照也没有改变历史摘要或隔离全部历史通道。

第二项从每个最大缺音段内截取 12 秒原波形，以同一权重作为独立音频重新编码和生成。八份分别生成 **43、77、62、72、49、61、78、104** 个音符（具体对应见 JSON），全部非空；仅两份自然结束，其余仍未学会正常停止。这同时改变了音频全局上下文、时间原点和谱面历史，不能归因到其中单独一项，更不代表这些短谱质量合格。它支持“整段缺音不是这段声音在任何输入条件下都无法出键”。

## 代码机制与下一步方向

1. `src/anchored_ar.py::frame_logits` 用当前隐藏状态和整曲音频 memory 做点积匹配，选下一帧；`time_intervals` 只限定未来有效区间，未对跨越大量未生成音乐的跳转单独建模。当前配置保留全局音频，未启用显式相对时间偏置。
2. `generate` 直接把时钟移到获选帧，随后才生成 NOTE。没有“逐段经过并检查覆盖”的状态，也没有回填过去时间的路径，因此一次错误决定可丢掉一分钟以上。
3. 当前训练使用真实谱面历史、真实时间训练下一事件。帧 CE 会惩罚选错时间，但只取 `−log p(真实下一帧)`：在真实帧概率相同的条件下，将错误概率放在近邻还是两分钟后，CE 相同。模型自身生成历史下的大跨度漏段及不可逆后果未在当前损失中单独监督。

综合原训练曲高拟合、新歌失败和本轮回放，证据指向**下一事件时间定位的泛化与生成历史下的稳定性不足，被自由选未来位置和不可逆前进放大**。尚不能据此确定唯一根因是参数规模、前端表示或历史摘要。

后续应优先验证时间头的跨段错误与覆盖训练目标，以及含模型自身错误历史的纠错训练；可以保持全局音频可见。先用这些固定缺音段验证干预能否改善，再做整曲评估。不能把有声等同于强制出键，也不能用固定密度、键型配额或事后补键冒充模型已学会编谱。本轮没有实施这些改动。
