# 第 3 阶段：历史时间扰动的受控对照

2026-10-31。**H1 的 400 轮训练与对照已完成。** 固定声学探针改善，随机组合起点小幅改善，但联合排布和受扰真实前缀恢复没有改善，因此不将历史噪声设为后续默认。第 2 阶段的随机组合门槛仍未通过，本阶段仅做受控归因，不推广到全 300 首，不替换产品权重。

H0 直接复用 E16-W1 的 400 轮无扰动结果；H1 从相同随机主干开始，使用同一 32 条音频与标签、样本顺序、dropout RNG、12,800 次更新及学习率。唯一训练差异是输入历史时钟的组级 ±20 ms 噪声。新增模块零噪声分支直接返回原 target，且不消费随机数；不是给旧 H0 临时加推理限制，也不是继承已拟合 H0 后多训 400 轮。

对每个 ANCHOR 到 END_GROUP 的同刻音符组共享一个扰动；BOS/窗口边界时刻保持不变。噪声从幅度、保序、当前窗口和下一干净目标仍可达的合法交集中均匀抽取，记录区间收缩次数，不把抽样后截断造成的尖峰当作自然分布。参考时间、布局、Hold 时长、free-x 坐标标签不改。输入 frames、28 维历史摘要与下一时间下界全部重算；独立 RNG 保存在续训断点中。小误差恢复并不等于漏组、错组或百秒跳转恢复。

已通过 25 项针对历史扰动、窗口协议与时间边界的测试，包含原目标不被修改、和弦共享时钟、跨窗 Hold 不拆分、64-bin residual 保留、所有目标仍可达及真实反向梯度。H1 路径为 `out/windowed_ar_20261031/history20`，源码提交 `58701c1`。

最终分别检查干净输入自由生成、干净真实前缀和相同受扰真实前缀的下一事件恢复；固定旧探针只评起点。恢复诊断使用预先固定的 900–907 共 8 个噪声种子；两个模型逐样本使用完全相同噪声。每个 split 有 1,120 个待恢复事件、640 个结束标签；本批构造样本间距足够，诊断中没有因可达性收缩噪声区间。

## 归因及下一步

无扰动 H0 已能在已见样本的 ±20 ms 历史误差下完全恢复；本诊断没有提供“此前主要缺乏这种小误差鲁棒性”的证据。H1 改善固定探针，却没有提高随机组合的受扰前缀恢复或联合排布，不能把固定探针收益解释成已经解决了生成历史分布问题。两组在正确历史下仍然定位不稳，条件映射泛化仍需单独解决。这里只测了时钟小扰动，没有测漏组、额外组、错误类型或百秒跳转恢复，也没有第二训练 seed。

下一步 free-x 先单独验证窗口协议，A/S 各自从同初始化重训；保留 H1 结果供后续更丰富数据与恢复任务对照，本轮不默认叠加其扰动，以免同时改变协议和历史训练。第 5 阶段的表示、编码器与容量还未执行。

H1 实际更新 12,800 次，训练循环 785 秒，最终条件时间 MAE 0.157 ms；资源、源码/权重哈希、逐噪声种子计数见 [原始报告](assets/windowed_ar_20261031/h0_h1_controlled_result.json)，复现脚本为 [summarize_history.py](assets/windowed_ar_20261031/summarize_history.py)。
