## 文件与复现

完整原始报告：`out/full_chart_comparison_val30/report.json`。
修复后谱面：`out/full_chart_comparison_val30/playable/<variant>/decoder/`。
使用 `python -m script.compare_full_charts` 重算，生成步骤见 README「完整验证集对照」。
新报告记录权重、谱面与列表 SHA-256；复用的旧报告缺少历史指纹，只能核对配置及权重修改时间。
数据、权重和谱面保留本地；该文档只保存数值结果。

## 本轮结论（2026-10-17）

后续定轨对照采用原转录器 + NMS35（阈值 0.7、间隔 35ms），全局 v2 继续作为
实验候选。NMS35 相对原始配置的 F1@25ms 增益为 +0.00730，配对 95% 区间
[+0.00216, +0.01245]，26/30 首提高；这是本轮较明确的节奏收益。

全局 v2 与 NMS35 的平均 F1@25ms 差仅 -0.0000135，区间跨 0；轨道 F1 虽从
0.3132 升到 0.3232，区间也跨 0。`Jingle Bell` 的 F1@25ms 从 0.5421 降到
0.4657，起点 596→449、音符 822→597；该曲仍保留在所有平均分和区间中。
完整集没有复现 6 曲子集里新节奏头的稳定额外收益。

本轮只比较冻结骨架，没有重训 AR 权重，也不修改通用生成入口的默认参数。
180 份跨路线/方案输出已统一检查和修复；4K 三套方案的静态冲突、时间范围、
位置与时长检查全部通过，但连续手速与人工试听/试玩仍未验收。main 保持不变。
