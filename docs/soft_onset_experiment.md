# 预测骨架显式入网：最小 A/B 训练协议

2026-10-22。用户已授权真实模型实验。第一阶段仅检验未阈值化的预测起音分数／时间偏移作为网络条件是否有用，不再用阈值调整替代。4K 与 free-x 分别训练和报告；第二阶段再加入因果历史状态与 free-x 连续位置反馈，之后才考虑模式辅助监督。

| 项目 | 固定要求 |
| --- | --- |
| A／B | 同架构、同旧权重初始化、同零初始化条件投影、同训练样本顺序与优化步数。A的额外条件为零，B为冻结音频模型预测的阈值前分数和时间偏移；其他音频条件相同 |
| 条件来源 | 只从音频计算，不从目标谱时间、类型、Hold或位置构造。冻结前端与时钟固定，按真实memory帧对齐，保留有效尾部；不静默丢弃不同频率的子帧预测 |
| 信息到达网络 | 一个batch核对B新分支非零梯度；初始A/B共享参数与输出一致。训练后在同B权重、同历史下切换预测／零条件，确认logits是否改变，不额外训练第三个模型 |
| 数据 | 首轮建议24训练曲／6开发留出曲，最终名单由可用数据与资源确定；按歌曲／音频源分离，不按loss挑曲。A/B用同一名单，完整头尾监督不满足时列出排除原因。留出曲不参与本轮梯度；已有开发验证集不改称未见测试集 |
| 训练 | 先最小pilot确认损失与梯度有限，再按预先固定步数完成A/B；不依据这6首的最终结果补训某一支或挑最优seed。四键型保留、Hold无配额、多指无默认上限 |
| 留出评分 | 同参考历史下分项bits：DT、NOTE位置／类型、DUR、EOS；free-x另列当前NOTE的连续offset误差。各项分母和失败保留，跨路线不直接比词表NLL大小 |
| 真实生成 | A/B都自由预测DT／NOTE，`skeleton_ticks=None`；至少预先定两首留出曲、同seed，原始输出为主，修复另列。检查自然EOS／预算耗尽、生成时域与起音分布、对编排参考的唯一起点误差与F1、有限pattern及未分类分母，保留音频预览。旧forced结果仅背景，不能把解码政策变化计作骨架输入收益 |
| 结论 | 报告实测改善、无改善或失败。参考谱只是一种编排，NLL与起音F1不能单独代替音乐／触屏质量；至少给出实际自由生成产物。产品默认不因实验运行成功而切换 |

实现与结果按对应分支推送，复用环境／数据／旧权重。余盘保留8 GiB，先估计训练主要工作集，只保留必要的最终实验权重；不重复全套工程测试、不新增通用审计系统。设计侧只做条件无泄漏／时间对齐／公平对照的必要检查，以及一次实际结果评价。
