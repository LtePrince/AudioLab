## 后续如何登记

统一表达：`AL-AR4K v0.5.1 / S / E14-S / e0160`，依次表示产品家族、开发版本、条件、运行、检查点。`model_latest.pt`只表示该运行的滚动断点，不能作为历史结果的唯一身份。

1. 新结构、条件接口或数据阶段增加次版本；独立登记的同结构续训/修复增加修订号。同一实验仅延长预算时保持版本，用阶段、父断点和epoch区分；E14的300→500轮仍为v0.5.1。
2. 新假设/配方/消融增加实验号；解码器参数、后处理、复放和诊断标明类别，不能写成重训。
3. 每组记录数据清单或缓存哈希、代码来源、父权重、条件输入、训练预算、输出协议、权重位置和评测证据。未知来源明确标未知。
4. 固定检查点或运输包记录SHA；滚动权重标记为可变，历史分数绑定具体epoch/step及原评测哈希。
5. 分别记录训练完成、完整生成、质量/试玩、网页加载兼容性。只通过文件完整性校验不能标为可用模型。
6. 更新总表与JSON；聊天、谱包交付和实验报告使用完整身份。训练中的进展带观察时间，避免把旧快照当实时状态。

本次整理只增加台账和命名约定，训练配方、采样设置及现有权重均未变动。
